## 1. Project Overview

Agents Studio is a multi-agent system built on Google's ADK framework. It contains five specialized agents, each designed for a specific domain task. Two agents received heavy development today: the **Hair System Visual Expert** and the **Marketing Image Generation Director**.

All agents run locally via `adk web src/agents` on port 8000, with a web-based chat/debug UI. They call the Gemini API through **Vertex AI** (not the Gemini API directly) to take advantage of Vincent's GCP credits and the 50% discount currently offered on Gemini 4 Argon.

### 2.4 Key Platform Findings (from today's research)

- **Vertex AI model IDs differ from Gemini API.** API uses `gemini-3.1-flash-image-preview`; Vertex uses `gemini-3.1-flash-image` (no `-preview` suffix)
- **Location matters.** `us-central1` returned 404 for most models. `global` works for all GA models
- **Gemini Omni Flash (video) not on Vertex AI.** The preview models (`veo-3.1-generate-preview`, etc.) were shut down Oct 22, 2026. Video generation requires Gemini API fallback or the Enterprise Platform GA Veo models
- **Context window on Vertex AI image model:** 131,072 tokens (vs 1M+ on API). This affects tool design — base64 image data must NEVER be returned in tool responses
- **Nano Banana 2.1** exists for Google AI plan subscribers; not available via Vertex AI SDK yet

## 3. What is Google Agent Studio / ADK (as of Nov 2026)

### 3.1 The Platform Landscape

Google's agent platform was rebranded at Cloud Next 2026 (April). The key components:

| Component | What it is | How we use it |
|---|---|---|
| **Agent Development Kit (ADK)** | Open-source Python/TS/Go/Java framework for building agents. v2.13.0 installed. | We author agents in Python, run locally with `adk web`, test via the built-in UI |
| **Agent Studio** (cloud.google.com) | Low-code visual builder. Design agents, tune prompts, connect data sources. Browser UI. | Not used yet — we're code-first. But the agents can be imported into Agent Studio later |
| **AI Studio Build** (aistudio.google.com) | Browser IDE. Imports from GitHub, builds full-stack apps, deploys to Cloud Run with free `ai.studio` subdomains | Our GitHub repo is ready for "Import from GitHub" into Build mode |
| **Agent Engine** (formerly Agent Runtime) | Managed runtime for deploying agents. Handles sessions, memory, scaling. | Deployment target when we move to production |
| **Memory Bank** | Managed cross-session memory service. LLM-extracted memories persist across conversations | Configured but not active (using in-memory for dev) |
| **RAG Engine / Data Stores** | Ingest documents → automatic embedding → semantic search at runtime | The `hair_system_bible.md` and brand docs are ready to ingest |
| **Model Garden** | 200+ foundation models including Gemini, Claude, Nano Banana, Veo | We use Gemini 4 Argon + Nano Banana 2 |
| **Model Tuning** | Supervised Fine-Tuning (SFT) + Preference Tuning (DPO) for Gemini models | SFT and DPO datasets prepared but not yet submitted |

### 3.2 ADK Architecture (how our agents work)

```
User message → ADK Runner
                  ↓
         gemini-4-argon (planning)
         "Should I call a tool?"
                  ↓
         Tool call dispatched
         (e.g., generate_hair_system_image)
                  ↓
         gemini-3.1-flash-image (Nano Banana 2)
         "Generate this image"
                  ↓
         Image saved to disk at .adk/generated/
         File path returned to planning model
                  ↓
         Planning model responds to user
         "Image generated at /path/to/file.jpeg"
```

**Critical architectural constraint discovered:** ADK feeds ALL tool responses back to the planning model as context. If a tool returns base64-encoded image data, the next planning call exceeds the context window and fails with 400 INVALID_ARGUMENT. **All generation tools now save to disk and return only a file path reference.**

### 3.3 Available Memory Options (not yet fully utilized)

| Option | Status | Notes |
|---|---|---|
| **In-Memory Session** | Active (dev default) | Session state lost on restart |
| **SQLite Session** | Available | `.adk/session.db` auto-created per agent |
| **Memory Bank** | Imported but not configured | Requires Vertex AI project setup. Provides cross-session LLM-extracted memories |
| **VertexAiRagMemoryService** | Available | Vector-based conversation retrieval via RAG Engine |
| **Custom (Milvus, AlloyDB)** | Available | For production-grade persistent memory |

### 3.4 GitHub Integration Path

AI Studio Build supports "Import from GitHub" (launched July 8, 2026). The workflow:

1. Push to `github.com/vincent-laroche/agents-studio`
2. Open [aistudio.google.com](https://aistudio.google.com) → Build → Import from GitHub
3. AI Studio transforms the repo into its runtime format
4. Iterate in Build mode, deploy to Cloud Run, or export back to GitHub

Our repo is structured to be compatible: `AGENTS.md` provides context, agents are in `src/agents/<name>/agent.py`, and `.env.example` documents required secrets.

## 4. Agent 1: Hair System Visual Expert

### 4.1 Purpose

Generates photorealistic images and video of men wearing custom hair replacement systems (hair systems / cranial prostheses). This is NOT a chatbot or consultant — it is a **visual generation engine**. Every user request must result in an image or video, never a text-only description.

### 4.2 Domain Knowledge

The agent encodes the full Hair Solutions Co. product taxonomy:

**Color system:** #1 Jet Black through #10 Platinum Blonde, plus grey blends (#1B10 through #1B50). Grey heavier at temples.

**Curl patterns (exact rod diameters):** Straight 32mm · Slight Wave 25mm · Body Wave 20mm · Medium Wave 15mm · Tight Wave 10mm · Afro Curl 4-8mm

**Density scale:** Light 70-80% · Medium-Light 80-90% · Medium 90-100% · Medium-Heavy 100-110% · Heavy 110-120%. Above 120% = unnatural helmet look.

**Base types:** Ultra-thin skin 0.03mm (near-invisible) · Thin skin 0.06-0.08mm · Swiss lace (finest) · French lace (durable) · Monofilament · Hybrid (skin front + lace body)

**Hair origins:** Indian Remy (medium, best value) · European (finest, premium) · Chinese Remy (thick, straight) · Brazilian Remy (body, volume)

**Front hairline graduation (critical):** Leading 0.5cm at 60-65% decreasing to 40% at edge. Single bleached knots. Baby hairs (fine, wispy, irregular). Scalp pore reflection. ZERO blunt edges, ZERO visible lace grid, ZERO dark knots.

**Before/After rules:** Same man, same face, same bone structure, same lighting, same camera angle, same wardrobe. Only difference: the hair.

**Attachment methods:** Daily tape · Extended tape · Liquid adhesive (Ghost Bond) · Hybrid (tape perimeter + adhesive front)

### 4.3 Tools

| Tool | What it does | Model |
|---|---|---|
| `generate_hair_system_image` | Generates a portrait with exact specs: color_code, curl_pattern, density_percent, base_type, hair_origin, hairline_style, style_description, age_range, lighting, camera | Nano Banana 2 |
| `generate_transformation_comparison` | Generates before (Norwood baldness) + after (hair system) frames. Facial identity preserved between frames | Nano Banana 2 |
| `generate_hair_system_video` | Generates video: lifestyle, transformation reveal, or hair movement | Gemini Omni Flash (API fallback) |
| `match_hair_color` | Maps natural language descriptions to exact color codes with grey blend recommendations | — |
| `recommend_base_type` | Recommends base type based on lifestyle, budget, exposed hairline preference | — |
| `calculate_density` | Calculates density based on age, Norwood level, style preference | — |

### 4.4 Prompt Engineering

The `build_image_prompt()` function constructs domain-accurate prompts with this structure:

1. Subject framing (ethnicity, age, face shape)
2. Hair system specifications (exact codes, not vague)
3. Hairline and attachment realism (the 0.5cm graduation rule)
4. Lighting and camera specs (85mm portrait, studio/golden/natural)
5. Quality directives (8K, photorealistic, skin pores)
6. **Negative constraints** (no blunt edge, no lace grid, no dark knots, no plastic shine, no helmet density)

Example output prompt excerpt:
> "0.03mm ultra-thin skin base, #3 Dark Brown Indian Remy hair, 20mm body wave, 95% medium density with 65% graduated front hairline, single bleached knots, baby hairs, 85mm f/1.4 portrait lens"

### 4.5 Issues Resolved During Development

| Issue | Root Cause | Fix |
|---|---|---|
| Agent described instead of generating | Planning model defaulted to text response | Placed "CRITICAL: CALL THE TOOL" as first instruction line |
| `gemini-2.5-flash` 404 | Model deprecated for new users | Switched to `gemini-3.8-flash`, then `gemini-4-argon` |
| Memory tool import error | `load_memory_tool` is a module, not a callable | Import `load_memory` and `preload_memory` (pre-built instances) |
| 400 token limit exceeded | Base64 image data returned in tool response, fed back to planning model | Save images to `.adk/generated/`, return only file path |
| Token limit persisted after image fix | Accumulated session history from failed retries | Fresh session solves it; instruction trimmed for leaner context |

### 4.6 Fine-Tuning & Evaluation

**SFT dataset:** `src/agents/hair_system_expert/tuning/sft_dataset.jsonl` — 10 examples of user→assistant pairs showing correct tool calling behavior with domain-accurate parameter extraction.

**DPO preference pairs:** `src/agents/hair_system_expert/tuning/preference_pairs.jsonl` — 20 pairs of preferred vs rejected responses. Covers: terminology (hair system vs wig), density limits, hairline graduation, ethnic accuracy, honest product representation, client empathy.

**Evaluation:** `src/agents/hair_system_expert/evaluation/test_questions.jsonl` — 20 test cases with expected tools and quality checks (e.g., "image_generated", "same_face_both_frames", "hairline_undetectable").

### 4.7 RAG Knowledge Base

**File:** `src/agents/hair_system_expert/knowledge/hair_system_bible.md` — 11-section complete technical reference covering product definition, base types, hair types, color system, curl patterns, density scale, hairline graduation, attachment methods, before/after standards, care & maintenance, and common AI generation mistakes.

**To activate RAG:** Upload this file to a GCS bucket → Create a Data Store in Agent Studio → Set `RAG_CORPUS_RESOURCE_NAME` in `agent.py` → The agent will ground responses in this document at runtime.

## 5. Agent 2: Marketing Image Generation Director

### 5.1 Purpose

Generates on-brand marketing visuals for Hair Solutions Co. using the Atelier Zero v7 design system. Creates marble head portraits, editorial collages, social media assets, and campaign visuals. Every image follows brand colors, composition rules, and voice guidelines automatically.

### 5.2 The Marble Head Concept

The brand's visual identity anchor is the **Carrara marble bust** — a classical sculpted male head and shoulders carved from white Carrara marble with:

- Soft grey veining and subsurface translucency
- Blank carved eyes (no pupils, no eyelashes, no human expression)
- Matte fractured edge at the shoulder truncation
- **Hyper-realistic human hair** as the ONLY living material — individual strands visible, natural irregular hairline where it meets the stone
- Mounted on a marble plinth

**Critical design decision (per Vincent, 2026-11-03):** The agent does NOT rely on fixed characters. Every marble head is a UNIQUE creation unless the user explicitly names Leo, Miles, Marc, or Ray. The four known characters (from the mascot library v2.0 at `/Users/vincent/01_hair_solutions_co/design/brand/marble heads/`) are available but not defaults.

### 5.3 Brand System (Atelier Zero v7)

**Source of truth:** `/Users/vincent/01_hair_solutions_co/design/brand/atelier_zero_design_system_artifact/project/tokens.json` and `atelier-zero-design-system-from-theme.md`

**Color palette:**
| Role | Token | Hex |
|---|---|---|
| Canvas | Paper | #EFE7D2 |
| Raised surfaces | Bone | #F7F1DE |
| Dark ground | Ink | #15140F |
| Primary accent | Coral | #FF5757 |
| Dark accent | Coral Soft | #F08E7C |
| Focus halo | Mustard | #E9B94A |
| Utility | Olive | #6E7448 |
| Secondary text | Ink Mute | #5A5448 |

**Coral rules:** SPOT COLOR ONLY. Five specific roles: display headline periods, section eyebrows, sequence numerals, single active state, one primary button per page. NEVER body text, NEVER surface fill, NEVER twice in one viewport.

**Typography:** Inter Tight (display/headings, sub-1.0 leading for display), Inter (body), Playfair Display italic (emphasis — family switch, never bold-inside-bold), JetBrains Mono (metadata, 11px UPPERCASE).

**Composition rules:**
- Film grain on all backgrounds (σ≈1.0) — flat fill reads wrong
- No shadows on light-canvas cards — lightness step IS elevation
- Shadows only inside Ink panel (cards rotated ±2°)
- One Ink section max per composition
- No gradients, no glows
- Collage plates: square 1:1, 4-8px radius
- Corner registration marks: 1px L-brackets in Ink

### 5.4 The Editorial Collage Language

Derived from the Krea marble exploration (`/Users/vincent/01_hair_solutions_co/design/krea_marble_exploration_2026_10_13/`) and Vincent's reference board:

- **Ground:** Aged Paper (#EFE7D2) with film grain texture
- **Coral sun disc:** Large, textured, prominent, partly behind the bust
- **Mustard disc:** Smaller, adds depth
- **Graphite elements:** Cloud engravings, fine orbital pencil lines
- **Halftone dots:** Sparse, floating
- **Torn-paper wedge:** Cracked-concrete texture crossing a lower corner
- **Numbering:** Sequential No.01, No.02... near upper right in clean serif
- **Mood:** Warm, weathered, layered editorial — NEVER bright corporate

### 5.5 Tools

| Tool | What it does |
|---|---|
| `generate_marble_head` | Generates a unique marble head portrait. Takes free-form face description, lighting style, optional pose/composition. Invent new faces each time |
| `generate_editorial_collage` | Generates a numbered editorial collage poster in the Krea style. Coral disc, Mustard accent, graphite elements, torn-paper wedge |
| `generate_social_asset` | Platform-specific (feed/story/reel/carousel) with campaign modes (general/black_friday/product_launch/editorial) |
| `generate_campaign_visual` | Flexible campaign visual. Can use marble heads or go free-form. Follows brand rules automatically |
| `get_brand_spec` | Lookup for brand colors, typography, marble concept, composition, collage language, voice |

## 9. Key Decisions Made Today

| Decision | Rationale |
|---|---|
| **Vertex AI over Gemini API** | Use GCP credits + Gemini 4 Argon 50% discount |
